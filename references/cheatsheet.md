# 决策规则速查 — 八字规则体系（四书合编）

| 能力 | 一句话规则 |
|---|---|
| 排盘与起运 | 按节气定年月柱，按日干定时柱 |
| 十神与关系 | 以日干为我，按五行生克与阴阳同异定十神 |
| 旺衰与月令 | 查日干在四支的十二长生 |
| 取用与忌法 | 从月令取用（或以病处定药） |
| 格局判定 | 以月令取格 |
| 病药与层次 | 找克害用神之字为病 |
| 大运与流年 | 定大运干支与交运关口 |
| 官杀混杂 | 判官杀是否混杂 |
| 伤官格 | 判官星是否伤尽 |
| 阳刃与特殊日格 | 查羊刃/日刃 |
| 神煞查法 | 按年干/日干/年支/日支查神煞 |
| 六亲（含小儿） | 十神映射六亲 |
| 女命 | 以官为夫、食伤为子女 |
| 性情与疾病 | 五行配五常论性情 |
| 从格与化气 | 验日主无根、旺神成局 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
