# 《渊海子平》术语词典（阶段 3 产出）

> 用途：整书共享术语。每个词条给「书中用法、与今人常识的差别、为什么重要」。
> 取材限于 `source/corpus/` 的「原文（含眉批）」段；引文已过 `tools/verify_quotes.py` 逐字核验。
> 凡涉时代局限者标 `epoch-limit`；凡书中两说并存、未决者标 `conflict`。

## 一、核心坐标

- **日主 / 日干**（第 65 章）：出生日天干，「以日为主，如人之己身」。不是太阳、也不是生日；它是全书唯一固定的「我」这个坐标。所有十神、旺衰、格局判断都围绕它，用错坐标系则整条推理链失效。
- **月令 / 提纲**（第 66、77 章）：「月令者，提纲也。看命先看提纲」。不是农历月份，而是月支所藏当令之气，是取用神与定格局的第一依据。`conflict`：第 65 章另有「论命者切不可泥之月令」一语，属全局校核的补充，两条并行。
- **四柱分属**（第 76 章眉批）：年干祖、月干父、日为己身、时为子息；书中另有「年为根、月为苗、日干为己身、时为花实」的生长比喻。

## 二、关系语言

- **十神**（第 65 章）：日干与他干的五类十种关系（官杀、财、印、食伤、比劫）。不是十位神灵；阴阳同异决定正偏。十神是全书唯一的关系语言。
- **官 / 杀**：正官（阴阳相异）与七杀（相同）。`conflict`：官杀可能并见而混杂，处置有「制伏」与「财通关」两说（needs-review N-11）。
- **食神 / 伤官**：我生者，阴阳相同为食神、相异为伤官。
- **正财 / 偏财**：我克者，阴阳相异为正财（妻）、相同为偏财（父、妾）。
- **正印 / 偏印（枭神、倒食）**：生我者；偏印又称枭神、倒食。
- **比肩 / 败财（劫财）**：同我者，阴阳相同为比肩，相异为败财、劫财。`conflict`：第 87 章另论两者名称与作用差异。

## 三、判断中枢

- **用神**（第 160 章眉批、第 280 章）：「用神者，月中所藏之字，如子宫取癸水之类。」不是「命局中最旺的字」，也不是后世扶抑流派的唯一喜用神；它是忌法的宾语，须随格局通变。`conflict`：与第 282 章「从重者论」并存，取用顺序未定（needs-review N-03）。
- **喜神 / 忌神**：生扶用神者为喜，克害用神者为忌。不是情绪化喜恶，而是用神关系上的加减项。
- **病 / 药**（第 282 章）：病＝克害用神之字；药＝能去此害之字。不是中医概念。「有病方为贵，无伤不是奇」，是断层次的主要手段。
- **四病（雕枯旺弱）与四药（损益生长）**（第 283、284 章）：病药说的操作化分类清单；四病共同前提是「有根」（根在苗先）。
- **中和**（第 77 章）：「人之命宜得中和之气，太过与不及同」。不是平均值；是趋势判据，并被病药说修正为「有偏有救方为贵」。
- **盖头**（第 286 章）：天干（头面）压制同柱地支之力的结构。喜神透干则吉、忌神透干为害立现；断流年先看天干所盖之字。

## 四、结构与格局

- **格局**：以月令为准对命局结构分类命名。全书分内十八格（虚拱、暗合、冲出、刑出取官）、外十八格（专旺与结构格）、杂气、特殊日格等。
- **取格法则**（第 178 章《宝法第一》）：「凡格用月令提纲，勿於傍求年日时为格」，旁求者作者称「百发百失」。
- **专旺五局**：炎上（丙丁火）、润下（壬癸水）、从革（庚辛金）、稼穑（戊己土）、曲直／仁寿（甲乙木）。`conflict`：稼穑格正文忌东方运，同章眉批称喜逢财地兼官杀。
- **杂气**：辰戌丑未四季库中藏财官印，须干头透出方为真格。
- **开库**：墓库须刑冲破害方开。`conflict`：非冲不开、刑冲破害皆可、原已有刑冲者再行反伤三说并存（needs-review N-06）。
- **从格（弃命从财／弃命从杀）**（第 130、132 章）：日主彻底无根无援时的例外许可；有根即不可从，最忌日主得根与比肩。
- **化气 / 化象**（第 162、167 章）：天干五合得月令之地则化（甲己化土等）。判读次序由总释给出：「先明从化为本，化不成方论财官」。忌争合、妒合与反本。`conflict`：化气与外十八格可同判一格（needs-review N-08）。
- **神趣八法八象**（第 164–172 章）：类、属、从、化、照、返、鬼、伏八种取象；总律「类属要身旺，而从化要衰」。`conflict`：类与属界定重叠，照／返／伏各有两义（needs-review N-07）。
- **官杀混杂**（第 70 章）：「官星要纯不要杂」，正官与七杀并见即混杂伤身。
- **伤官见官**（第 86 章）：「伤官务要伤尽，伤之不尽，官来乘旺，其祸不可胜言」；须伤尽或见财通关。
- **羊刃 / 飞刃**（第 54 章）：「禄过则刃生」；甲刃在卯、乙刃在辰……，对宫即飞刃。`conflict`：第 88 章「五阳有刃，五阴无刃」与第 54 章十干皆列刃位冲突（needs-review N-05）。
- **禄**（第 34 章）：天干本气所居旺位；「用之为禄不可冲」，且「凡人有禄必赖刃以卫之」。
- **三丘五墓**（第 180 章）：辰戌丑未重见，主骨肉刑悲、六亲疏离。`epoch-limit`

## 五、时间轴

- **大运 / 小运 / 流年（太岁）**（第 55、160 章）：「子平之法，大运看支，岁君看干，交运同接木」。大运自月柱起、十年一步；交运换甲与四维转角为关口。
- **十二长生**（第 15 章）：十天干在十二地支上的强度曲线（长生、沐浴、冠冕、临官、帝旺、衰、病、死、绝、胎、养），查表式工具。
- **藏遁 / 人元（地支藏干）**（第 59、61 章）：地支内部所藏天干，是取用神与论合化的实际作用单位。
- **司令分日**（第 15、59、60、76 章）：月令内不同天当令之字不同（如寅月余气、寄生、正合各占日数）。`conflict`：三个出处细节有差异。

## 六、加法符号（神煞与辅助）

- **神煞**（第 24–53 章）：贵人、驿马、空亡、华盖、孤寡等附加符号。不是独立判据；须与格局喜忌合看，权重低于格局。
- **天乙贵人**（第 24 章）：按日干或年干查支，辰戌二宫不临；落空亡或临恶煞则减力。
- **空亡**（第 142 章）：旬中所空之支，按五行分吉凶，且「二三反吉」。`conflict`：第 47 章眉批「水空则脱」（凶）与第 142 章「水空则流」（上吉）相反（needs-review N-01）。
- **胎元 / 息 / 变 / 通**（第 20–23 章）：胎息变通诸法。`conflict`：第 74 章称「子平之法不用胎元小运，不用纳音」，与本版收录诸章并存。
- **纳音**（第 14 章）：六十甲子纳音；第 74 章另给大衍数算法。`conflict`：与上一条冲突，须分层。

## 四书术语差异

### 用神（真诠）

- 本书定义："用神者，八字中所用之神也……八字中察其旺弱喜忌，或扶或抑，即以扶抑之神为用"
- 与通行用法：本书的用神是「为全局所用之神」，可由扶抑、病药、调候、专旺、通关五法取；渊海的用神偏「月令所藏之字」
- 差异书目：yuanhai-ziping

### 相神（真诠）

- 本书定义："月令既得用神，则别位亦必有相，若君之有相，辅者是也。"
- 与通行用法：本书独有。指辅佐用神、使全局成格的那一个字；渊海无此概念，最接近的是「药」，但药是去病，相是成格
- 差异书目：yuanhai-ziping

### 顺用 / 逆用（真诠）

- 本书定义："财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。"
- 与通行用法：顺用＝生之护之；逆用＝制之化之。这是本书的用神操作总纲
- 差异书目：—

### 救应（真诠）

- 本书定义："如官逢伤而透印以解之，杂煞而合煞以清之，刑冲而会合以解之。"
- 与通行用法：格局被破坏时的解救手段；救应之神多即相神。与渊海「药」同功，但覆盖范围更广（含合、会解冲）
- 差异书目：yuanhai-ziping

### 纯 / 杂（真诠）

- 本书定义："纯者吉，杂者凶。"
- 与通行用法：两个用神候选「互用而两相得」为纯，「两不相谋」为杂；渊海无此对概念
- 差异书目：yuanhai-ziping

### 有情 / 无力（真诠）

- 本书定义："其理之大纲，亦在有情无情、有力无力之间而已。"
- 与通行用法：判同一格局高低的两个维度：相神与用神的关系是否相生相护（情），相神是否有根（力）
- 差异书目：yuanhai-ziping
