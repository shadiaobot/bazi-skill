# 《神峰通考》主题定位（采集线第 0 步）

- **书目**：神峰通考 / 张楠（明·神峰子）/ 明代
- **版本**：`神峰通考-古籍典藏-luckclub.pdf`（348 页，114 章，全部含白话）
- **文本规模**：28.1 万字
- **定位**：**辟谬 + 病药**的双料专著；原名《神峰张先生通考命理正宗辟谬大全》

## 1. 一句话主张

**以日主与月令论旺衰、以病药定层次，凡五星、纳音、生肖、神煞、奇格与合婚之说，皆属谬说。**

## 2. 与前两本书的关系

| 议题 | 本书立场 | 与前两书的关系 |
|---|---|---|
| 病药说 | 全书第一紧要，且**本书记载与《渊海子平》第 282 章几乎同文** | 对《渊海子平》是**源头**（至少同源），对《子平真诠》是「化入成败救应」的原始形态 |
| 五星/纳音/生肖 | 「焚其版，火其书」级否定 | 与《渊海子平》大量使用纳音、生肖、神煞**正面冲突** |
| 神煞（天乙、日贵、魁罡…） | 名有数端、不根理出、虚诞 | 与《子平真诠》「星辰无关格局」**同阵营**，且措辞更激烈 |
| 奇格（趋乾、趋艮、拱禄、飞天） | 逐条点名「无中生有」「相为表里」 | 与《子平真诠》「拘泥格局」一致，构成**第三份反对证据** |
| 六亲 | 以宫位与星双看，「论六亲只是死格」 | 与《子平真诠》宫分法相近 |

一句话：**这本书是《渊海子平》神煞体系的第三个反对者，同时是病药说的文献源头。**

## 5. 学派立场

- **取用**：日主与月令对看，病药为第一紧要（「有病方为贵」）
- **旺衰**：看日主能否任财官，反对「只论财官生旺」
- **格局**：承认部分格（曲直、稼穑多富贵），否定大部分奇格
- **神煞**：全面否定

## 7. 已知风险

- **文本讹误多**：开篇即有「《王井奥诀》」「献天禄马」等讹字，须逐条核校
- **与渊海高度同源**：病药、动静、盖头、四病四药几乎同文，**不能重复计数**，应记为 corroboration（same/extends）
- **骂战文风**：「焚其版，火其书」这类表达属论辩修辞，提取时只取其判据，不取情绪
