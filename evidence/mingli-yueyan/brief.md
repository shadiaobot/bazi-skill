# 《命理约言》主题定位

- **书目**：命理约言 / 陈素庵（清）/ 清代
- **版本**：`命理约言-古籍典藏-luckclub.pdf`（258 页，124 章，全部含白话）
- **文本规模**：19.6 万字
- **定位**：**命理教科书**——作者自称对命学做「全面清理与标准化」，四卷本

## 1. 一句话主张

**看命大法不过生克扶抑：先定日干、次看月支、透干取格、扶抑取用，正格兼格与变格各有定式。**

## 2. 与前几本书的关系

| 议题 | 本书立场 | 关系 |
|---|---|---|
| 看命顺序 | 日干 → 月支 → 透干取格 → 扶抑取用 | 与渊海同源，但把「取格顺序」标准化 |
| 用神 | 「不过扶抑而已」，并递归调整（扶太过则抑其扶者） | **重定义**：比子平真诠的五法更简化 |
| 月令 | 先取当令、次看得势；**批评「运必不可冲月令」** | 与渊海「提纲忌冲」**相左** |
| 神煞 | 第 89–100 章逐项论述（贵人、驿马、空亡、纳音…） | 保留神煞，但逐条辨析 |
| 格局 | 正格六类 + 变格六类 + 兼格 | 最系统的格局分类 |
| 特殊格 | 暗冲、暗合、趋乾趋艮、魁罡、六乙鼠贵…均有专论 | 保留并解释，不似神峰那样斥为谬说 |

## 5. 已知风险

- **与渊海同源**：看命总法、十神各论大量沿用渊海，重复走 corroboration
- **教科书体例**：条目密集、彼此独立，适合逐条提取
- **对神煞的处理**：既收录又辨析，需区分「查法」与「评价」
